# Alexandra Degans · Kinésiologie

Site vitrine immersif (Astro + GSAP), hébergé sur GitHub Pages : https://alexandradegans-kinesiologie.com

- `src/data/` — contenus centraux (coordonnées, soins, tarifs, médias)
- `src/components/TreeOfLife.astro` — l'arbre de vie, signature du site
- `src/scripts/motion.ts` — animations au scroll
- `docs/` — storyboard Higgsfield, redirections Wix, guide de publication

`npm install` puis `npm run dev`.
